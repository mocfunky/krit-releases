# Krit Android 1.1.5

Published July 18, 2026.

This is the current Android beta package. It includes Krit's native mobile
shell, persistent authenticated sessions, microphone and media permission
handling, native Home/Friends/DMs/Servers/Voice navigation, corrected system
bar insets, reliable back handling, uploads and downloads, fullscreen media,
and Krit launcher/splash branding.

Android 7.0 or newer is required. This APK is distributed for sideloading while
the production store-signing and store-release work remains in progress.

The APK SHA-256 is published in `release-history.json`.
